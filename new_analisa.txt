=======================================================================
ROOT CAUSE
=======================================================================
1) `.ws-body` adalah grid dua kolom tanpa `grid-template-rows`. Track baris
   implisit `auto` mengambil tinggi max-content dari isi kolom kanan, sehingga
   kolom kanan bisa lebih tinggi dari `.ws-body`, meluber, dan bagian bawah daftar
   terpotong tanpa scroll.
2) Di dalam kolom kanan tidak ada rantai flex yang benar: `.block` (CHANGES) tidak
   `flex-shrink:0`, `.explorer-block` tidak `flex:1 1 auto; min-height:0`,
   `.explorer` tidak `overflow-y:auto`. Akibatnya tidak ada elemen yang menjadi
   scroll owner dan overflow dipotong oleh parent.

=======================================================================
FIX (web/frontend/src/styles.css — seluruhnya CSS)
=======================================================================
- .ws-body            : + grid-template-rows: minmax(0, 1fr)   (batasi baris tunggal)
- .ws-col.right       : + overflow: hidden; min-height: 0       (ikat anak ke tinggi kolom)
- .ws-col.right > .block:not(.explorer-block) : + flex: 0 0 auto (CHANGES tetap di atas)
- .explorer-block     : + flex: 1 1 auto; min-height: 0; overflow: hidden
- .ex-head            : + flex: 0 0 auto                        (header tetap terlihat)
- .explorer           : + flex: 1 1 auto; min-height: 0; overflow-y: auto; overflow-x: hidden;
                        + scrollbar-width: thin; scrollbar-color: var(--border) transparent;
                        + .explorer::-webkit-scrollbar / -track / -thumb / -thumb:hover (tema gelap)
- .ex-name            : + min-width: 0                          (ellipsis + tanpa horizontal overflow)
- @media (max-width:1080px) [mode stacked]:
    .ws-body        : grid-template-rows: none                 (dua baris menyusun vertikal)
    .ws-col.right   : overflow: visible                        (tak terpotong saat tak dibatasi grid 1fr)
    .explorer-block : flex: 0 1 auto; max-height: 60vh         (daftar tetap punya batas tinggi -> scroll aktif)

CATATAN SESI INI (hardening tambahan di atas perbaikan sebelumnya):
  - .ws-col.right { min-height: 0 }  -> menutup celah agar rantai flex kolom kanan
    dijamin boleh menyusut di grid track minmax(0,1fr).
  - .ex-name { min-width: 0 }        -> flex item boleh menyusut; nama file panjang
    di-truncate ellipsis dan tidak memicu horizontal overflow.
  - .ws-col.right { overflow: visible } pada media query stacked -> menghindari
    daftar terpotong saat kolom tidak lagi dibatasi grid track 1fr.
