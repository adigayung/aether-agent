1) OBSERVATION (kondisi sebelum perubahan)
--------------------------------------------------------------------------------
- ConsultantChat.vue memakai prop `running` (:running="isRunning" dari App.vue)
  dan mengikat `:disabled="running"` pada .run-task-btn. Karena isRunning = true
  bila ADA task global lain yang berjalan, user tidak bisa mengantrikan Task
  Proposal baru — padahal queue global (concurrency=1) justru untuk itu.
- App.vue::isRunning = computed dari task.status (task = task yang sedang
  ditampilkan di Workbench, bukan task milik Task Proposal tertentu).
- Tombol copy sudah ada (.cmsg-actions > .copy-btn) tetapi dirender sebagai
  SIBLING di luar bubble (.ctext / .consultant-md), jadi terlihat "menggantung"
  di bawah card.
- .consultant-selects.inline (Provider/Model dropdown) dirender sebagai blok
  TERPISAH setelah .consultant-proposal (bukan di dalam card).
- Kontrak layout modal TIDAK diubah: .consultant-messages tetap scroll owner
  (flex:1 1 auto; min-height:0; overflow-y:auto), .consultant-foot tetap sibling
  flex-shrink:0, .consultant-proposal tetap DI DALAM .consultant-messages.

--------------------------------------------------------------------------------
2) ROOT CAUSE
--------------------------------------------------------------------------------
#1 Run Task disabled terlalu dini: satu boolean `running` dipakai untuk dua
   makna berbeda — (a) "agent global sedang sibuk" (informasi) dan (b) "task
   Proposal INI sedang berjalan / sudah disubmit" (harus memblokir). Karena
   keduanya disatukan, agent busy memblokir antrian.
#2 Copy button berada DI LUAR elemen bubble (sibling setelah .ctext /
   .consultant-md), sehingga tidak terafiliasi visual dengan card pesan.
#3 Provider/Model dipindah ke dalam .consultant-messages tapi sebagai elemen
   terpisah, bukan bagian dari card Task Proposal.

3) CHANGES
--------------------------------------------------------------------------------
A. web/frontend/src/components/ConsultantChat.vue
   - Prop baru: `submittedTaskId` (task_id yang baru dibuat App.vue dari aksi
     Run Task) dan `terminalTaskId` (task_id terakhir yang mencapai status
     terminal). Prop `running` DIPERTAHANKAN sebagai informasi "agent busy"
     (tidak lagi memblokir tombol) — kontrak prop tidak diputus.
   - State baru: `submittedTaskId` (lokal), `terminalTaskId` (lokal),
     `runDisabled = Boolean(submittedTaskId) && submittedTaskId !== terminalTaskId`.
   - `runTask()`: guard `if (!target || runDisabled.value) return;` lalu set
     `submittedTaskId.value = "__pending__"` + reset `terminalTaskId` SEBELUM
     emit — anti double-submit instan (tanpa menunggu round-trip).
   - watch(props.submittedTaskId) -> catat task milik tombol ini.
   - watch(props.terminalTaskId) -> bila task terminal, `runDisabled` menjadi
     false => tombol kembali enabled ("Run Task").
   - Template: `<button class="run-task-btn" :disabled="runDisabled">` dengan
     ikon panah tampil saat `!runDisabled` dan label `Running…` saat disabled.
   - Copy button dipindah KE DALAM bubble:
       * user  : `<div class="ctext"><span class="ctext-body">…</span>
                  <div class="cmsg-actions">…</div></div>`
       * assistant: `<div class="consultant-md md">
                      <div class="md-body" v-html="renderMarkdown(...)"></div>
                      <div class="cmsg-actions">…</div>
                    </div>`
     v-html dipindah ke `.md-body` (inner) agar tombol copy bisa berada di dalam
     bubble tanpa tercampur konten markdown. Selector `.consultant-md.md p`
     tetap berlaku (descendant). Desain tombol copy tidak diubah.
   - Provider/Model: markup `.consultant-selects.inline` DIPINDAH KE DALAM
     `.cp-foot` pada card `.consultant-proposal`.

B. web/frontend/src/App.vue
   - Ref baru `submittedTaskId` + `terminalTaskId`.
   - `runConsultantTask()`: setelah `await submitTask(text)`, set
     `submittedTaskId.value = task.id || ""` (task milik tombol Run Task).
   - `handleEvent()`: pada `task_completed` / `task_failed` / `task_cancelled`
     set `terminalTaskId.value = evt.task_id || task.id || ""` — sehingga tombol
     Run Task proposal tersebut kembali enabled pada status terminal.
   - Teruskan `:submitted-task-id` dan `:terminal-task-id` ke <ConsultantChat>.

C. web/frontend/src/styles.css
   - `.cp-foot`: dari `justify-content:flex-end` menjadi
     `display:flex; align-items:flex-end; justify-content:space-between;
      gap:10px;` => Provider/Model di KIRI, Run Task di KANAN, sejajar.
   - `.consultant-selects.inline`: dari bar kotak (padding/border/background)
     menjadi `flex:1 1 auto; min-width:0; padding:0; border:0;
      background:transparent;` => menyatu di dalam card.
   - `.run-task-btn`: tambah `flex:0 0 auto` agar tombol tidak menyusut.
   - `.cmsg-actions`: `margin-top` 1px -> 8px (kini berada DI DALAM bubble).
   - Tambah `.ctext-body { display:block; white-space:pre-wrap; word-break:break-word }`.
   - Tambah `.consultant-md .md-body { min-width:0 }`.
