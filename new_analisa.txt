R3. FORMAT ISI ENTRI + CONTOH KUTIPAN
================================================================================
Format = `entry-v1` (konstanta BIBLE_FORMAT di aether_store.py:62).

Pola header tiap file kategori (dibuat BibleStore._header, aether_store.py:333-340):
      # bible:<kategori>
      <!-- AETHER BIBLE (machine-readable). format=entry-v1. -->
      <!-- Setiap entri dimulai dengan marker '## entry'. -->
      <!-- Tambahkan knowledge lewat ProjectBrain/AETHER; jangan edit manual. -->

Pola 1 entri (dibuat BibleStore._serialize_entry, aether_store.py:349-362),
dipisah oleh marker `## entry`; antar entri dipisah baris kosong:

      ## entry
      - id: <uuid-atau-id-semantik>
      - source: <ai|system|consultant|...>
      - confidence: <float 0..1>
      - created_at: <ISO-8601 UTC>
      - updated_at: <ISO-8601 UTC>
      - content: <JSON-encoded (string/objek)>

Field (6): id, source, confidence, created_at, updated_at, content.
 - `content` diserialisasi via json.dumps (aether_store.py:350) dan saat dibaca
   di-parse balik via json.loads dengan fallback teks mentah
   (BibleStore._parse_content, aether_store.py:408-414).
 - `id`, `source`, `confidence`, `created_at`, `updated_at` = skalar; `content`
   boleh string biasa ATAU objek JSON (mis. {"title","status","area",...}).
