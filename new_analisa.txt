4. PERUBAHAN YANG DILAKUKAN
--------------------------------------------------------------------------------
### A. Composer multi-line (ConsultantChat.vue)
- <input type="text"> diganti <textarea rows="1" class="input-a"> dengan:
    ref="composer", v-model="input", @input="autoGrow", @keydown="onKeydown".
- Ditambah logika auto-grow:
    const COMPOSER_MAX_HEIGHT = 140;
    function autoGrow() {
      el.style.height = "auto";
      el.style.height = Math.min(el.scrollHeight, 140) + "px";
      el.style.overflowY = el.scrollHeight > 140 ? "auto" : "hidden";
    }
- Ditambah resetComposer(): setelah mengirim, tinggi textarea dikembalikan ke 1 baris.
- Keyboard (KEPUTUSAN TERKUNCI):
    Enter biasa  = baris baru (default textarea, TIDAK di-preventDefault).
    Shift+Enter  = kirim (preventDefault + send()).

### B. Lebar modal & ruang ketik (styles.css)
- .modal.consultant-m : max-width 720px -> 860px (width: 90vw tetap, margin tetap).
- .consultant-foot    : align-items: center -> flex-end (tombol send sejajar bawah
  saat textarea tumbuh).
- .consultant-foot .input-a : padding 9px 13px -> 11px 15px; font-size 13px -> 14px;
  line-height 1.5; resize: none; min-height: 42px; max-height: 140px;
  overflow-y: hidden; font-family: inherit.

### C. Ukuran teks (proporsional, tetap AETHER-like)
- .ctext        : 13px / 1.55 -> 14px / 1.6
- .consultant-md: 13px / 1.55 -> 14px / 1.6
- .crole        : 10.5px -> 11.5px
- .cs-label     : 11px -> 12px
- .cm-label     : 11px -> 12px
- .cm-hint      : 11px -> 12px

### D. Persistensi chat selama sesi browser (App.vue)
- <ConsultantChat v-if="consultantOpen" ...>  ->  v-show="consultantOpen".
- v-show menjaga komponen tetap ter-mount (hanya display: none saat tertutup),
  sehingga ref 'messages' dan sesi Consultant tetap hidup selama sesi browser
  (close/open modal tanpa reload).
- Ditambahkan komentar penjelas pada markup.
- CATATAN: scope mengikuti instruksi = cukup selama SESI (bukan lintas reload).
  Solusi ini MURNI FRONTEND (hanya ganti v-if -> v-show); tidak perlu backend.

### E. Kebersihan minor
- Assignment redundan ke computed read-only `lastProposal.value = ...` di send()
  DIPERIKSA: sudah tidak ada di source (no-op, tidak perlu diubah).
