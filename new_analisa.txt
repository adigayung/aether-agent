RINGKASAN
--------------------------------------------------------------------------------
Memperbaiki 3 masalah UX pada Consultant Chat:
  (1) Klik "Run Task" tidak lagi menutup modal Consultant Chat.
  (2) Celah/ruang kosong vertikal internal (bawah bar MODE, atas composer) lebih tipis.
  (3) Box Consultant memiliki ukuran TETAP (lebar & tinggi konsisten) dari chat
      kosong s/d penuh — tidak lagi memendek saat belum ada percakapan.

Semua perubahan FRONTEND-ONLY. Tidak ada perubahan Python/backend, kontrak API,
Agent execution, task lifecycle, logging, SessionStore/SSE, atau Project Bible.

FILES CHANGED
--------------------------------------------------------------------------------
1. web/frontend/src/App.vue
   - Fungsi runConsultantTask(text): menghapus dua baris yang menutup modal dan
     memindahkan navigasi.
       SEBELUM:
         async function runConsultantTask(text) {
           if (!text) return;
           consultantOpen.value = false;   // menutup modal Consultant
           activeNav.value = "agent";      // memindahkan nav ke view agent
           await submitTask(text);

           if (!text) return;

         }
   - Menambah komentar penjelas bahwa modal sengaja dibiarkan terbuka.

       max-height: calc(100vh - 100px)  ->  height: calc(100vh - 48px)

ROOT CAUSE
--------------------------------------------------------------------------------
(1) Handler event `run-task` di App.vue (dipanggil oleh ConsultantChat.vue setelah
    klik "Run Task") secara eksplisit menutup modal:
       consultantOpen.value = false;
       activeNav.value = "agent";
    ConsultantChat.vue sendiri hanya emit("run-task", lastProposal.value) dan TIDAK
    menutup modal. Modal dikontrol App.vue via v-show="consultantOpen". Jadi satu-
    satunya penyebab modal tertutup adalah dua baris di handler App.vue.

(2) Celah vertikal internal terasa lebar karena padding/gap vertikal yang relatif
    besar (.consultant-head 14px, .consultant-messages 18px, .consultant-modes 10px,
    .consultant-foot 12px, gap pesan 16px). Keluhan "margin atas/bawah lebar"
    berasal dari celah INTERNAL ini, bukan dari margin box (margin 50px auto memang
    simetris).

(3) Modal memakai `max-height` (bukan `height`) sehingga tingginya mengikuti isi:
    saat chat kosong modal memendek, saat penuh memanjang -> ukuran box tidak
    konsisten.

FIX
--------------------------------------------------------------------------------
(1) Hapus `consultantOpen.value = false;` dan `activeNav.value = "agent";` dari
    runConsultantTask. submitTask() TIDAK menyentuh consultantOpen, sehingga task
    tetap terkirim ke Agent sementara modal Consultant tetap terbuka dan tetap
    berada di percakapan Consultant. (Tidak ditambahkan indikator baru agar tetap
    minimal; prioritas utama modal tetap terbuka terpenuhi.)

(2) Pangkas padding/gap vertikal internal secara proporsional (nilai di atas),
    tanpa mengubah horizontal padding maupun struktur layout. Tetap rapi, tidak
    sesak.

(3) Ganti `max-height: calc(100vh - 100px)` menjadi `height: calc(100vh - 48px)`
    dan turunkan margin box menjadi `24px auto` agar total tinggi + margin tetap
    <= viewport (100vh - 48px + 2*24px = 100vh) sehingga tidak overflow pada
    viewport pendek. Modal kini berukuran tetap sejak dibuka; .consultant-messages
    (flex:1 1 auto; min-height:0; overflow-y:auto) mengisi sisa tinggi dan tetap
    menjadi satu-satunya scroll owner.
