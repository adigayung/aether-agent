--------------------------------------------------------------------------------
RINGKASAN
--------------------------------------------------------------------------------
Tujuan: mengaktifkan kemampuan vision untuk AETHER Consultant dengan risiko
minimal:
  (1) menambah dukungan pesan multimodal (image content-parts) pada layer provider
      yang SUDAH ADA, dan
  (2) memungkinkan user melampirkan/mengirim image di chat AETHER Consultant,
      sehingga image diteruskan ke LLM dan Consultant dapat "melihat"-nya.

Hasil: SELESAI. Image dikirim sebagai content-parts format OpenAI-compatible
(image_url dengan data URL base64) untuk provider OpenAI-compatible (OpenRouter,
DeepSeek, OpenAI, dsb.), dan sebagai field `images` untuk Ollama. Pesan text-only
berperilaku persis seperti sebelumnya (backward compatible). Modul vision existing
(ImagePreprocessor) dipakai apa adanya untuk memproses/resize/kompresi gambar.

  Pesan dengan parts image -> content diubah menjadi content blocks:

  Part {"type":"audio"} dsb. diabaikan; bagian teks tetap dipertahankan.

  requests.post non-stream). Tidak perlu fallback streaming khusus image.

File: src/agent_ai/providers/ollama.py (degradasi aman, additive)

  sesuai format multimodal Ollama; content list (bentuk OpenAI) -> teks gabungan.
  Pesan text-only diteruskan apa adanya.

Keputusan: format OpenAI-compatible `image_url` dipakai karena semua provider
cloud AETHER (OpenRouter/DeepSeek/OpenAI) dulunya memakai skema OpenAI; Ollama
diberi adapter terpisah agar tetap benar bila dipakai untuk vision.
